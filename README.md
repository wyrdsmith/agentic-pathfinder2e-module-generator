# Instant Pathfinder (Working Name)
This will house the development of the Pathfinder 2e Module Generator.

## The Goal
To create and develop an adventure module generator for Pathfinder 2e.

### What is an Adventure Module?
An adventure module consists of a quest, which is a story with three acts. Each act has a number of scenes, and 
each scene has an encounter. The adventure module also includes a number of NPCs and locations, as well as treasure.
These are all generated by the system. A module should be balanced for a party of 4 level 1 characters (number of 
characters and level will be adjustable) and the sum of all encounters should have an experience total of 1000, the amount needed to gain a single level.

#### Why does every scene have an encounter, and why only one?
LLMs are dumb. They are not capable of reliably creating the logic chains required to produce multiple encounters per scene let alone how to write a scene that's purely for character interaction. The easiest way I could approach the problem of roleplay scenes was to treat them as social encounters where the players attempt to influence one or more NPCs. This way the adventure module will still feel like a published adventure as it's played. And limiting the number of encounters to one per scene keeps things simple for an otherwise incredibly complex task.

### Why an LLM-Based Generator?
Gamemasters have always had access to random tables for generating game content. These days there are a plethora of random generators for encounters, loot, npcs, etcetera, that can be found online. The purpose of this tool is not to replace the GM or those other tools, but to provide a tool that can generate balanced, ready-to-play, adventure modules in an effort to get people playing at the table faster. An inexperienced GM might use this tool to create a short, simple adventure for their friends and test the waters of gamemastering, while more experienced GMs might use it to generate a quick adventure for a one-shot or a side quest for their main campaign.

This tool is not intended to replace homebrew content, nor is it a replacement for published adventure modules that have gone through rigorous review and testing by some of the most creative minds out there. It's going to have balancing, continuity and logic issues. What will be produced by this tool will in no way be a finished product. But it could be a starting point. LLMs should never displace a person or replace critical thinking, but they can be a useful tool in the creative process if utilized correctly.

My best hope for this project is that it will help people better learn and understand Pathfinder 2e and gamemastering while providing another asset in a GM's toolkit for having fun with their friends.

## Current Progress
I've begun actual work on the module generator. As of this moment, the generator is capable of producing a three-act quest with 5-9 scenes per act. I'm still working out how to generate explicit details such as encounter balancing, treasure and NPCs. But each scene provides a summary of the events in the scene, the location of the scene, the encounter type intended for that scene as well as whether or not the scene offers a rest opportunity after the encounter.

I'm using a multi-agent approach to the module generation with Gemma4:12b being used for the creative writing and Qwen2.5 being used for extracting the data from the creative writing and formatting it into pydantic objects. I need to develop out tools to allow me to pass the quest object as part of the pydantic dependencies to give agents greater awareness of the quest data. I'm still getting a few random hallucinations, like suddenly switching languages or random numbers appearing in the scene and act summaries. Once I figure out dependency injection, the next step is scene by scene generation.

I also updated the plot_hooks table to quest_concepts to include all the data about the quest idea so that agents are less likely to repeat settings, npcs, and other quest details.
